# Instagram運用AI社員システム 事務向け業務マニュアル

## 1. 目的

このマニュアルは、御社の事務スタッフがInstagram運用案件を進行するための業務手順です。

アプリの操作マニュアルではなく、クライアントへの指示出し、進行管理、投稿予約確認、実績回収、改善提案までの実務の流れをまとめています。

## 2. 役割分担

### クライアントが行うこと

- 写真や動画の撮影
- 必要素材の提出
- 投稿内容の確認
- Instagramへの投稿または投稿予約
- 投稿後のインサイト数値の共有
- 修正希望や確認事項への返信

### 御社事務スタッフが行うこと

- 案件情報の管理
- AI社員への投稿案作成依頼
- 投稿内容の整理
- クライアントへの撮影指示
- クライアントへの素材提出依頼
- 投稿予約内容のLINE共有
- 承認状況の管理
- タスク管理
- 投稿後の実績入力
- 実績に基づく改善提案の作成

### AI社員が行うこと

- 投稿企画の作成
- 投稿文の作成
- 参考アカウントに寄せた投稿案の最適化
- 撮影指示や必要素材の整理
- タスク抽出
- 投稿実績の分析
- 月次レポート作成

## 3. 連絡ルール

クライアントへの指示出しは、LINEグループで行います。

送信元は、事務用の公式LINEを使用します。

LINEグループには原則として以下の人が入ります。

- クライアント担当者
- 御社事務スタッフ
- 必要に応じて社内確認者

## 4. 基本業務フロー

1. 案件情報を確認する
2. ブランド情報、ターゲット、参考アカウントを整える
3. AI社員チャットで投稿案を作成する
4. 投稿案を保存する
5. 投稿詳細で内容を整える
6. 必要な撮影・素材を整理する
7. LINEグループでクライアントへ指示を出す
8. 素材や確認結果を受け取る
9. 投稿予定日時を設定する
10. LINEグループで投稿予約内容を共有する
11. 投稿後に実績を入力する
12. 実績分析AIで改善提案を作る

## 5. 案件開始時の業務

新しい案件を開始するときは、事務スタッフが最初に案件情報を整えます。

### 入力する情報

- 案件名
- 会社名
- 業種
- ブランドコンセプト
- ブランドトーン
- 必ず含める訴求
- 使用してはいけない表現
- ターゲット情報
- 行動してほしい内容
- AI社員設定
- 参考アカウント分析

## 6. 参考アカウント分析

参考アカウントは、投稿の方向性を整えるために使います。

ただし、丸写しはしません。構成、見せ方、訴求の型だけを参考にし、クライアントのブランドに合わせて変換します。

### 登録する内容

- 参考アカウント名
- 参考URL
- 参考にする理由
- 強み
- 見た目・デザインの特徴
- 投稿内容・構成の特徴
- 真似しない点
- 自社投稿への取り入れ方

## 7. 投稿案作成業務

投稿案はAI社員チャットで作成します。

### AI社員への依頼例

```text
今月のInstagram投稿案を3本作ってください。
参考アカウントの構成に寄せつつ、ブランドトーンは親しみやすくしてください。
目的はLINE予約の増加です。
```

```text
この案件向けに、撮影が必要な投稿案を作ってください。
クライアントがスマホで撮影できる内容にしてください。
```

```text
この参考画像に寄せて、フィード投稿の本文と撮影指示を作ってください。
```

AIの返信が使える内容であれば、投稿案として保存します。

## 8. 投稿内容整理

投稿案として保存した後、投稿詳細で以下を整えます。

- 投稿タイトル
- 投稿本文
- CTA
- ハッシュタグ
- 投稿予定日時
- ステータス

投稿内容は、クライアントにそのまま見せても分かる状態まで整えます。

## 9. 撮影・素材提出の指示出し

撮影や素材提出はクライアントが行います。

事務スタッフは、クライアントが迷わず動けるようにLINEグループで具体的に指示します。

### 指示出しで必ず入れること

- 何を撮影するか
- 何枚または何本必要か
- 縦向き・横向き
- 明るさや背景
- 入れてほしいもの
- 入れないでほしいもの
- 提出期限
- 送付先

### 撮影指示テンプレート

```text
お世話になっております。
次回投稿用の素材撮影をお願いいたします。

【撮影内容】
・〇〇の写真を3枚
・〇〇している様子の短い動画を1本

【撮影の向き】
・スマホ縦向き

【撮影時のポイント】
・できるだけ明るい場所で撮影してください
・背景に不要なものが入らないようお願いいたします
・商品やサービス内容が分かるように近めで撮影してください

【提出期限】
〇月〇日 〇時まで

撮影できましたら、このLINEグループに送付をお願いいたします。
```

### 素材提出依頼テンプレート

```text
お世話になっております。
次回投稿作成にあたり、以下の素材をご共有ください。

【必要素材】
・〇〇の写真
・〇〇の動画
・掲載してよいキャンペーン情報
・金額や期間などの最新情報

【確認したいこと】
・今回特に訴求したい内容
・掲載NGの表現や写真

〇月〇日までに、このLINEグループへご共有をお願いいたします。
```

## 10. クライアント確認

投稿内容をクライアントに確認してもらうときは、確認してほしいポイントを明確にします。

### 確認依頼テンプレート

```text
お世話になっております。
次回投稿案の確認をお願いいたします。

【確認していただきたい点】
・投稿本文に誤りがないか
・サービス内容や金額に相違がないか
・掲載NGの表現や写真がないか
・投稿予定日時に問題がないか

問題なければ「OK」とご返信ください。
修正がある場合は、このLINEにてご指示ください。
```

## 11. 投稿予約内容の共有

投稿予約が完了したら、投稿詳細画面の `LINE共有文` を使います。

### 手順

1. 投稿一覧を開く
2. 投稿タイトルを開く
3. 右側の `LINE共有文` を確認する
4. `LINE用文面をコピー` を押す
5. 事務用公式LINEからLINEグループへ貼り付ける

### 送信前の確認

- 投稿予定日時が入っている
- 投稿本文が最新になっている
- CTAが入っている
- ハッシュタグが入っている
- クライアント名や案件名に誤りがない

## 12. ステータス管理

投稿ごとに進行状況を管理します。

| ステータス | 事務スタッフの対応 |
| --- | --- |
| アイデア | まだ検討中。投稿化するか判断する |
| 企画中 | AIと内容を作成中 |
| 事務確認中 | 事務側で誤字や内容を確認する |
| 承認待ち | クライアントまたは社内確認者の返答待ち |
| 承認済み | 投稿予約へ進める |
| 投稿予約済み | LINEで予約内容を共有する |
| 投稿済み | 実績入力へ進める |
| 保留 | いったん停止 |
| 却下 | 投稿しない |

## 13. タスク管理

必要な作業はタスク管理に登録します。

### 登録するタスク例

- クライアントへ撮影依頼
- 素材回収
- 投稿本文確認
- 投稿画像作成
- クライアント確認依頼
- 投稿予約確認
- 投稿後インサイト回収
- 実績入力

タスクは、誰が見ても次に何をすればよいか分かる名前にします。

## 14. 投稿後の実績入力

投稿後、クライアントからInstagramインサイトの数値をもらい、投稿実績入力に保存します。

### クライアントへ依頼する数値

- リーチ
- 表示回数
- いいね
- コメント
- 保存
- シェア
- 動画再生数
- プロフィールアクセス
- Webクリック
- LINE追加
- 問い合わせ
- 予約
- 売上金額

### 実績共有依頼テンプレート

```text
お世話になっております。
投稿後の振り返りのため、Instagramインサイトの数値共有をお願いいたします。

【共有いただきたい数値】
・リーチ
・表示回数
・いいね
・コメント
・保存
・シェア
・プロフィールアクセス
・LINE追加や問い合わせがあればその件数

スクリーンショットでの共有でも問題ございません。
```

## 15. 改善提案業務

実績を入力したら、実績分析AIを使って改善提案を作成します。

### 確認する観点

- 反応が良かった投稿
- 保存が多かった投稿
- クリックやLINE追加につながった投稿
- 反応が弱かった投稿
- 次回改善するべき見出し
- 次回改善するべき画像
- 次月の投稿方針

### クライアントへの改善提案テンプレート

```text
お世話になっております。
直近の投稿実績をもとに、次回以降の改善方針を共有いたします。

【良かった点】
・〇〇の投稿は保存数が高く、情報整理型の投稿が合っている傾向です

【改善点】
・冒頭の見出しをもう少し具体的にすると、反応が伸びる可能性があります

【次回方針】
・悩み訴求から始める投稿を増やします
・写真は明るめで、サービス内容が一目で分かるものを使用します

次回投稿では、上記を反映して作成いたします。
```

## 16. 月次業務

月末または月初に、月次レポートを作成します。

### 月次業務の流れ

1. 投稿済みのステータスを確認する
2. 投稿実績が入力されているか確認する
3. 未入力があればクライアントへ数値共有を依頼する
4. 月次レポートを生成する
5. 改善方針を確認する
6. 必要に応じてクライアントへ共有する

## 17. 注意事項

- クライアントへの指示は、必ずLINEグループで行います。
- 送信元は事務用公式LINEを使います。
- AIの文章はそのまま送らず、事務スタッフが確認してから送ります。
- 参考アカウントは丸写ししません。
- 金額、期間、キャンペーン内容は必ずクライアント確認を取ります。
- 誇張表現、断定表現、薬機法や景表法に触れる可能性がある表現は避けます。
- 投稿予約後は、LINEグループで予約内容を共有します。
